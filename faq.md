# FAQ

**App not installed.** The APK did not match the installed signature, or the version code
is older. Install the newest APK from [releases](https://github.com/jcufyr6d5djj-beep/aether/releases/latest); do not uninstall
the app first, chats would be lost.

**The model answers but tools never run.** Check Settings → Tools and the provider's tool
support. Tool calls require a model that supports function calling.

**No internet in the runtime.** Open Settings → Runtime and refresh the environment; the
proot image needs one successful download before offline use.

**Where are my chats stored?** On the device, in the app's private storage. They are not
uploaded anywhere; only model requests leave the phone.
